# 🍰 Cardápio Léle da Cuca

Cardápio online moderno, leve e interativo desenvolvido para o negócio de doces e salgados. O sistema conta com categorias separadas, controle de quantidade de itens em tempo real, cálculo automático do valor total e integração direta para envio do pedido formatado via WhatsApp.

## 🚀 Funcionalidades
- **Navegação por Categorias:** Filtros rápidos para Bolos, Caseiros, Copos da Felicidade, Doces/Tortas e Salgados.
- **Carrinho Interativo:** Botões de adição e remoção direta na tela (+ e -) com atualização instantânea do total.
- **Pedido via WhatsApp:** Botão de finalização que gera a mensagem completa com o nome do cliente, itens escolhidos, observações e valor total, enviando diretamente para o atendimento.
- **Design Responsivo:** Otimizado para visualização perfeita em celulares e computadores.

## 🛠️ Tecnologias Utilizadas
- **HTML5** (Estruturação)
- **CSS3** (Estilização com identidade visual personalizada)
- **JavaScript** (Lógica do carrinho, filtros e integração com o WhatsApp)
